# Cilyo

منصة فيها ثلاث أشياء مربوطة ببعض:

- **متجر ومعرض:** ألعاب وبرامج ويب بتشتغل بالمتصفح، وأعمال مرئية (أفلام، مسلسلات، أنمي). كله مجاني هلأ.
- **سيرفر محادثة لكل عمل:** بينعمل تلقائيًا لما ينتشر العمل.
- **استوديوهات ومشاريع مشتركة:** شركاء بيشتغلوا على عمل واحد، كل واحد مع مساعد الـAI تبعه، بعقد وميثاق وحصص وموافقات.

هاي النسخة مبنية لـ **Firebase**. النسخة القديمة اللي كانت بتشتغل على الكمبيوتر موجودة بمجلد `legacy-local`.

## كيف مركّبة

كل ناشر استوديو:

- **الاستوديو الشخصي** بينعمل تلقائيًا مع حسابك، وبتنشر منه مباشرة من «ارفع عمل».
- **الاستوديو المشترك** بين شركاء، وبيفتح بعد ما يوقّع الكل عقده.

وفي ثلاث مستويات ما بتختلط:

| المستوى | شو بيحدد | وين |
| --- | --- | --- |
| عقد الاستوديو | الأعضاء، ونسبة الاستوديو من كل عمل | استوديوهاتي ← الاستوديو ← العقد والأعضاء |
| ميثاق المشروع | الأدوار وأوزانها، وقاعدة القرار، وحصص هاد المشروع | المشروع ← الميثاق والحصص |
| المهام | مين مسؤول عن أي دور، والاتفاقات بين الأدوار | المشروع ← الاتفاقات والموافقات |

قواعد مهمة:

- **الحصة بتنكسب بالتسليم.** دور الإنتاج (برمجة، رسم، سيناريو) بينكسب لما يتسلّم ويعتمده الشركاء. دور الخدمة (تسويق، إدارة مجتمع) بينكسب على فترات.
- **المكتسب بيضل لصاحبه** حتى لو طلع أو انسحب منه الدور. واللي ما انكسب بيرجع للمشروع.
- **النشر بالمتجر** بدّه موافقة كل مشاركي المشروع.
- **قاعدة القرار** بيختارها الميثاق: بالإجماع، أو القائد بيحسم عند الخلاف.
- **مشارك بمشروع واحد:** القائد بيعزم أي مستخدم للمشروع بدون ما يصير عضو بالاستوديو.
- **لوحة الفرص:** الاستوديو بينشر دور مفتوح، والناس بتتقدم بتخصصاتها.
- **السجل** بينكتب تلقائيًا وما حدا بيعدّله.

## جرّبها على كمبيوترك أول (بدون Firebase)

هاي أسرع طريقة تشوف النظام كله. بتشغّل الموقع الحقيقي مع قواعد السيرفر الحقيقية، بس على قاعدة بيانات مؤقتة بالذاكرة.

لازم يكون عندك [Node.js](https://nodejs.org) نسخة 20 أو أحدث.

```
git clone https://github.com/limonatkh/cilyostore.git
cd cilyostore
cd functions
npm install
cd ..
npm run preview
```

بعدها افتح <http://localhost:4600>.

- اعمل حسابين (بمتصفحين، أو نافذة عادية ونافذة خاصة) وجرّب الاستوديو المشترك.
- كل البيانات بتنمسح لما تسكّر السيرفر.
- هاد الوضع للتجربة بس: ما فيه قواعد حماية القراءة ولا دخول Google.

## الرفع على Firebase

### 1. جهّز المشروع (مرة وحدة، من موقع Firebase)

1. أنشئ مشروع من [console.firebase.google.com](https://console.firebase.google.com).
2. حوّله لخطة **Blaze**. دوال السيرفر والتخزين بدهم إياها. فيها استخدام مجاني ضمن حدود، وحط تنبيه ميزانية بمبلغ صغير.
3. فعّل **Authentication**، ومنها طريقتين للدخول: Email/Password و Google.
4. فعّل **Firestore Database** بوضع production، واختار منطقة قريبة.
5. فعّل **Storage**.
6. من Project settings ← Your apps، أضف تطبيق **Web**.

### 2. ارفع (من كمبيوترك)

بدّل `PROJECT_ID` برقم مشروعك (بتلاقيه بـProject settings).

```
npm install -g firebase-tools
firebase login

git clone https://github.com/limonatkh/cilyostore.git
cd cilyostore
node scripts/setup.mjs PROJECT_ID
firebase hosting:sites:create PROJECT_ID-games

cd functions
npm install
cd ..
firebase deploy
```

بعدها الموقع على: `https://PROJECT_ID.web.app`

ملاحظات على أول رفع:

- بياخد حوالي 10 دقايق، وممكن يسألك تفعّل خدمات. وافق.
- إذا فشل رفع الدوال أول مرة، استنى دقيقتين وشغّل `firebase deploy --only functions`.
- المتجر ولوحة الفرص ممكن يطلعوا «قاعدة البيانات لسا بتتجهز» أول كم دقيقة، لحد ما تخلص الفهارس.
- إذا الاسم `PROJECT_ID-games` مأخوذ، اختار اسم ثاني، وشغّل `node scripts/setup.mjs PROJECT_ID الاسم`، وحط عنوانه بـ`gamesOrigin` بملف `public/config.js`.
- إذا طلع «ما لقينا إعدادات Firebase»، انسخ الـ`firebaseConfig` من Project settings لملف `public/config.js`.

### 3. خلّي حالك مشرف المنصة

المشرف بيشوف البلاغات وبيشيل الأعمال المخالفة.

1. سجّل دخول بالموقع، وبعدين من لوحة Firebase ← Authentication انسخ الـUID تبع حسابك.
2. من Firestore أنشئ مجموعة اسمها `admins`، وفيها مستند رقمه هو الـUID، وفيه أي حقل (مثلًا `note: "owner"`).

## ربط مساعد الـAI

من الموقع: اضغط على اسمك فوق ← الإعدادات ← «اعمل رمز موصل». بيطلعلك أمر جاهز لـClaude Code وملف جاهز لـVS Code مع Copilot.

المساعد بيشتغل باشتراك كل واحد العادي، وبيتبع نفس قواعد الموقع: ما بيوافق عن شريكك، ولا بيعلّم اتفاق منفّذ إذا مش دورك.

## الأعمال المرئية

الفيديو نفسه بينرفع على YouTube أو Vimeo، وبـCilyo بينحط رابطه. هيك ما في تكلفة استضافة فيديو. كل عمل مرئي إله حلقات وسيرفر محادثة.

## الاختبارات

```
npm test
```

بتفحص قواعد السيرفر: الحسابات، والنشر، والعقد، والميثاق، والحصص، والموافقات، والموصل، وتشغيل ملفات الأعمال.

## شو انفحص وشو لسا

- **انفحص:** قواعد السيرفر كلها (22 اختبار)، وجولة كاملة على الواجهة بثلاث مستخدمين، وتحميل دوال السيرفر والدخول على محاكي Firebase.
- **ما انفحص على Firebase حقيقي:** قواعد الحماية (`firestore.rules` و`storage.rules`) وقراءة البيانات من Firestore. أول رفع هو أول تشغيل إلهم، فمتوقّع جولة تصليحات.

## حدود هالنسخة

- كل الأعمال مجانية. ما في دفع ولا توزيع أرباح فعلي، والحصص مسجّلة كاتفاق بين الشركاء.
- العقد والميثاق قوالب للتجربة. عشان يكونوا ملزمين قانونيًا لازم يراجعهم محامي.
- ملف العمل لحد 100 ميغا، وكل ملف جوّاه لحد 30 ميغا.
- كل الأعمال بتشتغل على نفس موقع الألعاب: معزولة عن حسابات المنصة، بس مش عن بعضها.
- ما في حد لعدد الحسابات أو سرعة الرسائل. قبل فتح المنصة للعامة لازم ينضاف App Check وحدود استخدام.
- بقاعدة «الإجماع»، غياب مشارك بيوقّف القرارات لحد ما ينشال بموافقة الباقين.

## ملفات المشروع

```
public/            الموقع (js/driver.js هو الملف الوحيد اللي بيحكي مع Firebase)
functions/         دوال السيرفر. القواعد كلها بـ functions/lib
firestore.rules    قواعد حماية قاعدة البيانات
storage.rules      قواعد حماية التخزين
firebase.json      إعدادات الموقعين والدوال
scripts/           setup (ربط المشروع) و vendor-firebase (تحديث مكتبة Firebase)
tests/             الاختبارات والسيرفر التجريبي
legacy-local/      النسخة القديمة اللي كانت بتشتغل على الكمبيوتر
```
