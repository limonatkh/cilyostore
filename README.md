# Cilyo

متجر ألعاب ويب مجانية، لكل لعبة فيه سيرفر محادثة، ومعه استوديوهات تطوير بيشتغل فيها أكثر من شخص على لعبة وحدة، كل واحد مع مساعد الـAI تبعه.

هاي **نسخة تست** بتشتغل على كمبيوترك، بدون Firebase ولا أي خدمة خارجية.

## شو فيها

- **حسابات:** تسجيل دخول باسم مستخدم وكلمة سر.
- **المتجر:** أي حدا بيرفع لعبة ويب (ملف zip فيه `index.html`) وبتنعرض فورًا.
- **صفحة اللعبة:** اللعبة بتشتغل جوّا الصفحة، وجنبها **سيرفر اللعبة** بقنواته (عام، أخبار، بلاغات أخطاء، يوميات التطوير). الأخبار واليوميات بس لفريق اللعبة.
- **الاستوديو:**
  - إنشاء ودعوة شريك، وعقد بخيارات (الملكية، والخروج) وبنود ثابتة.
  - ما بيفتح إلا لما كل الأعضاء يوقّعوا. أي تعديل على العقد أو عضو جديد بيرجّع التواقيع من الأول.
  - بعد التوقيع بينعمل **سيرفر خاص** بالأعضاء، بقنوات: عام، قناة لكل طبقة، المشروع، الاتفاقات، الموافقات، التجارب، السجل.
- **المشروع:** خمس طبقات جاهزة، ولكل طبقة مسؤول. الطبقة بدون مسؤول بياخدها أي عضو، واللي إلها مسؤول هو بس بينقلها. ورابط مستودع GitHub مع زر «افتح بـVS Code».
- **الاتفاقات:** طبقة بتقدّم إشي وطبقة ثانية بتعتمد عليه. حالاتها: مقترح ← متفق عليه ← منفّذ ← معتمد.
  - الاقتراح أو التعديل بيروح لموافقة مسؤولي الطبقتين.
  - «منفّذ» بيعلّمه مسؤول الطبقة اللي بتقدّم.
  - «معتمد» بيعلّمه مسؤول الطبقة اللي بتعتمد.
- **التجارب:** رفع نسخة zip للتجربة، أو مشاركة رابط (مثلًا GitHub Pages).
- **النشر:** من نسخة مرفوعة، وبدّه موافقة كل الأعضاء. لما يوافقوا، اللعبة بتنزل بالمتجر وبينعمل سيرفرها العام تلقائيًا.
- **السجل:** كل إشي بينكتب تلقائيًا (مين عمل شو ومتى)، وما حدا بيقدر يعدّله.
- **ربط المساعد:** نقطة MCP على `/mcp`. مساعدك بـVS Code (Claude Code أو Copilot) بيشتغل باشتراكك العادي، وبيقدر يقرأ الطبقات والاتفاقات، ويقترح اتفاقات، ويبعت رسائل بسيرفر الاستوديو. وبيتبع نفس القواعد: ما بيوافق عن شريكك، ولا بيعلّم اتفاق منفّذ إذا مش طبقتك.

## التشغيل

### 1. Node.js

لازم يكون عندك Node.js نسخة 18 أو أحدث. عشان تتأكد، افتح التيرمنال واكتب:

```
node -v
```

إذا ما طلع رقم، نزّله من [nodejs.org](https://nodejs.org) (نسخة LTS).

### 2. شغّل Cilyo

```
git clone https://github.com/limonatkh/cilyostore.git
cd cilyostore
npm install
npm start
```

بعدها افتح بالمتصفح: <http://localhost:4000>

- كل البيانات بتنحفظ بمجلد `data/` جوّا المشروع. إذا بدك تبدأ من الصفر، سكّر السيرفر واحذف المجلد.
- السيرفر بيشغّل منفذين: `4000` للموقع، و`4001` للألعاب المرفوعة. الألعاب على منفذ لحالها عشان تكون معزولة عن حسابات الموقع.

## إدخال صاحبك من جهازه

صاحبك ما بيقدر يوصل لـ`localhost` تبعك، فبنستخدم «نفق» مجاني من Cloudflare بيعطيك رابط عام مؤقت.

1. ثبّت `cloudflared`:
   - Windows: `winget install --id Cloudflare.cloudflared`
   - Mac: `brew install cloudflared`
2. افتح تيرمنالين وشغّل بكل واحد نفق:
   ```
   cloudflared tunnel --url http://localhost:4000
   ```
   ```
   cloudflared tunnel --url http://localhost:4001
   ```
   كل واحد بيطبعلك رابط شكله `https://...trycloudflare.com`. الأول للموقع، والثاني للألعاب.
3. سكّر Cilyo وشغّله من جديد مع رابط الألعاب:
   - Windows (PowerShell):
     ```
     $env:GAMES_ORIGIN="https://رابط-الألعاب.trycloudflare.com"; npm start
     ```
   - Mac / Linux:
     ```
     GAMES_ORIGIN=https://رابط-الألعاب.trycloudflare.com npm start
     ```
4. ابعت لصاحبك **رابط الموقع** (النفق الأول). إنت كمان استخدمه بدل `localhost`.

الروابط بتتغير كل ما تشغّل الأنفاق من جديد، وكل إشي بيشتغل بس لما كمبيوترك والسيرفر شغالين.

## ربط مساعدك

1. من الموقع، ادخل على «ربط المساعد» واضغط «اعمل رمز».
2. انسخ الأمر اللي بيطلعلك:
   - **Claude Code:** أمر `claude mcp add ...` بتشغّله بالتيرمنال (أو تيرمنال VS Code).
   - **VS Code مع Copilot:** محتوى ملف `.vscode/mcp.json`.
3. احكي مع مساعدك عادي، مثلًا:
   - «شو الاستوديوهات والمشاريع اللي أنا فيها بـCilyo؟»
   - «اقرأ مشروع القلعة بـCilyo وقلي شو طبقاتي والاتفاقات اللي بتخصني»
   - «اقترح اتفاق: حدث التقاط المفتاح، من أنظمة اللعب للواجهة والصوت»
   - «احكي لشريكي بقناة عام إني خلصت الباب»

الرمز بيظهر مرة وحدة. لا تشاركه: اللي معه بيشتغل باسمك. إذا عملت رمز جديد، القديم بيوقف. وإذا الرابط تغيّر (نفق جديد)، أضف الموصل من جديد بالرابط الجديد.

## سيناريو تست مقترح

1. إنت وصاحبك تعملوا حسابات.
2. إنت تنشئ استوديو وتعزمه. هو يقبل، تختاروا خيارات العقد، وتوقّعوا الاثنين.
3. بقناة «المشروع»: أنشئ مشروع، وحط رابط مستودع GitHub، وكل واحد ياخد طبقاته.
4. كل واحد يفتح المشروع بـVS Code ويربط مساعده.
5. واحد يقترح اتفاق (من الموقع أو عن طريق المساعد)، والثاني يوافق من قناة «الموافقات».
6. ارفعوا نسخة zip بقناة «التجارب» وجربوها.
7. اطلبوا النشر ووافقوا الاثنين. بتلاقوا اللعبة بالمتجر مع سيرفرها.

## حدود هالنسخة

- قاعدة البيانات ملف JSON على جهازك، ومناسبة للتست بس.
- بعد ما يفتح الاستوديو، ما في لسا تعديل للعقد ولا إضافة عضو جديد (بدهم موافقة الكل، وهاي مرحلة جاية).
- كل الألعاب المرفوعة بتشتغل على نفس منفذ الألعاب، فهي معزولة عن الموقع بس مش عن بعضها.
- ما في استرجاع كلمة سر.
- المحادثة جوّا الموقع للناس بس. الـAI بيشتغل من VS Code باشتراك كل واحد.

```
server/db.js      حفظ البيانات بملف
public/           الواجهة (index.html, app.js, style.css)
```
